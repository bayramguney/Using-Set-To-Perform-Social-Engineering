# 🎭 Assisted Live Lab: Using SET to Perform Social Engineering

## 📌 Overview

This CompTIA Security+ Assisted Live Lab demonstrates how the **Social-Engineer Toolkit (SET)** can be used to simulate real-world social engineering attacks in a controlled environment. The lab highlights how attackers exploit human behavior rather than technical vulnerabilities to gain unauthorized access or sensitive information.

**Note:** This lab is intended for educational purposes only and was completed in an authorized training environment.

---

## 🎯 Lab Objectives

By completing this lab, I learned how to:

- Understand the purpose of the Social-Engineer Toolkit (SET).
- Explore common social engineering attack techniques.
- Observe how phishing campaigns can be created using SET.
- Understand the risks associated with human-targeted attacks.
- Identify security controls that help defend against social engineering.

## 🧪 Lab Activities

### Part 1: Launch SET

- Opened the terminal in Kali Linux.
- Started the Social-Engineer Toolkit.
- Reviewed the available attack options.

### Part 2: Configure a Social Engineering Attack

- Explored the Social Engineering Attacks menu.
- Selected a phishing-related attack scenario.
- Configured the required options in the lab environment.

### Part 3: Simulate the Attack

- Generated the phishing resources.
- Observed how SET prepares the attack.
- Reviewed the attack workflow from the attacker's perspective.

### Part 4: Analyze the Results

- Examined how users could be deceived.
- Identified indicators of a phishing attack.
- Discussed defensive measures to prevent similar attacks.

## 🧠 Key Takeaways

- Social engineering targets people rather than technology.
- Attackers often impersonate trusted organizations or individuals.
- Phishing remains one of the most common initial attack vectors.
- User awareness is one of the strongest defenses against social engineering.
- Technical controls should be combined with security awareness training to reduce risk.

---

## 🛡️ Defensive Best Practices

- Verify unexpected requests before responding.
- Never enter credentials into suspicious websites.
- Inspect email addresses, links, and attachments carefully.
- Enable Multi-Factor Authentication (MFA).
- Report suspicious emails to the security team.
- Participate in regular security awareness training.
